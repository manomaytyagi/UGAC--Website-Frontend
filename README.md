# UG Academic Council — IIT Mandi

Official website of the UG Academic Council, Student Gymkhana, IIT Mandi. A central portal for academic governance — covering council history, B.Tech. curriculum structures, academic opportunities, and procedural guides.

Built by students, for students.

## Stack

- **Frontend:** React + Vite
- **Backend:** FastAPI (async), PostgreSQL (Neon), Redis (Upstash), AWS S3
- **Admin:** SQLAdmin panel at `/admin`
- **Deploy:** AWS ECS Fargate (backend), Vercel/Netlify (frontend)

## Setup

```
npm install
npm run dev
```
